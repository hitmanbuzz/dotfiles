# **My Arch Linux Dotfiles**

> *My simple arch linux config/dotfiles (some configs are from omarchy)*

#### NOTE:
> Run `packages.sh` script first then run `stowing.sh` later.

### Install Packages
```
chmod +x packages.sh
./packages.sh
```
    
### Symlink Config
```
chmod +x stowing.sh
./stowing.sh
```
