# **My Arch Linux Dotfiles**

> *My simple arch linux config/dotfiles*

#### NOTE:
> Run `packages.sh` script first then run `stowing.sh` later.

- Enable `mulitlib` in `etc/pacman.conf`

### Install Packages
```
chmod +x packages.sh
./packages.sh
```
    
### Symlink Config
```
chmod +x stowing.sh
./stowing.sh
```
